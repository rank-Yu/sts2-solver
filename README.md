# 尖塔求解器 · STS2 Solver

[English](README.en.md)

《杀戮尖塔 2》的战斗求解 Mod，面向单人模式。进入战斗后，它读取当前局面和真实的随机数状态，搜索整场战斗的出牌路线，再通过游戏自己的操作入口自动出牌、用药，逐个动作核对实际结果。

《杀戮尖塔 2》里退出重进会从头重打这场战斗，战斗内的随机结果是确定的，求解器正是靠这一点预测每一步。战斗结束后才会揭晓的东西（例如战后奖励）求解器不会去看。

本 Mod 只接管战斗；地图、事件、商店等其余操作仍由玩家完成。

它的搜索策略和局面估分移植自 [CombatSolver](https://github.com/Torch1230/CombatSolver)（战斗路线求解器），模拟内核是重写的：战斗状态是一块紧凑的连续内存，复制一个分支只是一次内存拷贝，搜索时不再克隆游戏对象。

## 和原 CombatSolver 的对比

同样 108 个战斗局面，两边都用中档、全自动打完整场：

| 角色 | 局面 | 胜场（本 Mod / 原 CombatSolver） | 两边都赢的局面平均失血 |
|---|---:|---:|---:|
| 铁甲战士 | 21 | 20 / 20 | 19.6 / 22.9 |
| 静默猎手 | 24 | 17 / 16 | 9.4 / 9.7 |
| 故障机器人 | 21 | 20 / 18 | 22.7 / 25.1 |
| 亡灵契约师 | 21 | 18 / 18 | 19.9 / 22.4 |
| 储君 | 21 | 20 / 17 | 20.6 / 22.1 |
| **合计** | **108** | **95 / 89** | **18.7 / 20.7** |

| 战斗类型 | 局面 | 胜场（本 Mod / 原 CombatSolver） | 两边都赢的局面平均失血 |
|---|---:|---:|---:|
| 普通 | 40 | 40 / 40 | 11.1 / 12.2 |
| 精英 | 40 | 34 / 31 | 23.9 / 24.8 |
| 首领 | 28 | 21 / 18 | 26.5 / 32.6 |

原 CombatSolver 赢下的局面本 Mod 全部赢下，另外多赢 6 局；两边都没赢的是同样 13 局。两边都赢的 89 局里，本 Mod 失血更少的 27 局，原 CombatSolver 更少的 10 局，相同的 52 局。

开局搜索用时（两边基本都只在开局搜一次，之后沿用这条路线）：

| | 中位 | 平均 | 最长 |
|---|---:|---:|---:|
| 本 Mod | 2.2 秒 | 3.4 秒 | 44.9 秒 |
| 原 CombatSolver | 8.5 秒 | 13.4 秒 | 120.4 秒 |

105 个生成牌组里，本 Mod 有 93 个搜得更快。

测试条件：

- 局面：五个角色各 21 个随机生成的牌组（进阶 10，普通 8 场、精英 8 场、首领 5 场），加 3 个静默猎手的固定牌组首领战。
- 原 CombatSolver：0.50.1 之后的 main（`5c773caa`），在无头运行的游戏本体里全自动打完整场，智能药水。3 个固定牌组的局面它的测试工具设不了金币，用的是 99 而不是 35。
- 本 Mod：在离线内核里全自动打完整场，用生产的中档预算。
- 用时：只比 105 个生成牌组的开局搜索。两边在同一台机器（Intel Core Ultra 9 285K）上离线运行，不启动游戏画面，搜索并行度都是 4；原 CombatSolver 用它自带的离线宿主跑生产搜索流程。

## 安装

需要游戏 v0.111.0，以及 RitsuLib 0.6.0 或更新版本。

1. 单独安装 RitsuLib。
2. 把发布包里的 `Sts2Solver/` 目录放进游戏的 `mods/` 目录。

可以和原 CombatSolver 同时安装，两个都能搜索，但每回合只让一个执行：两个同时自动出牌或替你选牌会互相干扰。同时安装时，本 Mod 只在全自动档接管回合开始的选牌页面。

## 使用

- 战斗中屏幕左上方显示求解器面板：搜索进度、整场路线、当前执行到哪一步。拖动标题栏移动，拖动边缘缩放，可以收起。
- 标题栏有三档：**手动**时两个按钮都由你按；**自动搜索**时每回合自动搜索，你按“执行本回合”；**全自动**时搜索和执行都自动进行。首次安装默认自动搜索，档位跨战斗、跨重启保留。
- 底栏左边是搜索键（开始搜索 / 重新搜索 / 停止搜索），右边是执行键（执行本回合 / 停止执行）。停止只管本回合，下一回合照常按档位走。
- 执行中发现实际结果和预测不符，或者某个动作无法执行，会立即停下，不自动重搜；你可以点“重新搜索”。全自动因此暂停时，点标题栏的“全自动”恢复。
- 遇到不支持的内容（例如其他 Mod 加入的卡牌）会明确拒绝，不会乱打。
- 标题栏的“设置”里可以改出牌速度、搜索档位（默认中档）、搜索并行度、搜索内存上限和面板透明度；“药水”“成长”打开逐瓶药水策略和局外成长策略；有盗贼的战斗可以在提示条里选择保住还是放走被偷的东西。改动在下一次搜索时生效。
- 详细说明见 [Mod 说明](docs/mod.md)。状态和错误写在游戏日志里，条目前缀是 `[Sts2Solver]`。

## 构建

需要 .NET 9 SDK 和本机的游戏文件。把 `src/Mod/local.props.example` 复制成 `src/Mod/local.props`，填好游戏和 RitsuLib 的路径，然后：

```bash
dotnet build src/Mod -c Release
```

产物在 `artifacts/mod/Sts2Solver/`。测试版构建和更多说明见 [Mod 说明](docs/mod.md)，开发文档入口是 [docs/README.md](docs/README.md)。
